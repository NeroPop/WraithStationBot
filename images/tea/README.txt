TEA PICTURES
============

Put tea or kettle pictures in this folder. For every tea alarm, the bot picks one of them
at random and shows it in the alarm message.

- Allowed file types: .png, .jpg, .jpeg, .gif and .webp
- Keep each file under 8 MB (bigger files are skipped)
- File names do not matter, and this README is ignored
- After adding or removing pictures: commit, push to GitHub, and restart the bot's server

The bot also needs the "Attach Files" permission to show a picture. Without it, the alarm still
goes out and still pings, just without a picture.
